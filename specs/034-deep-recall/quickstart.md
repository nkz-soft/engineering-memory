# Deep Recall validation after implementation

1. From the feature worktree, sync the locked environment with `uv sync --frozen`.
2. Run `uv run pytest -q tests/unit/test_deep_recall.py tests/unit/test_deep_recall_cli.py tests/integration/test_deep_recall_mcp.py` once those files exist. The scenarios import synthetic Claude Code and Codex history, verify both anchors, and assert zero foreign reads, malformed or fabricated citations rejected, and explicit evidence gaps at the caps. The integration fixture uses deterministic adapter doubles for retrieval and synthesis and a real normalized archive.
3. Run `uv run pytest -q`, `uv run ruff check .` and `uv run ruff format --check .` for regression and style checks.
4. For a configured backend smoke test, use only synthetic fixtures in an isolated bank/archive, configure the dedicated synthesis settings documented by the implementation, and run `uv run engineering-memory deep-recall "Why did we change the cache policy?" --project demo --json`. Call MCP `deep_recall` with the same inputs. Confirm oldest event first, a citation from each source, and resolution through `get_conversation`. Run an unrelated question and confirm the result describes insufficient evidence or the gaps in support.
