# Validate the cited session handoff

Run after Phase 2 implementation. Use synthetic data in a disposable archive and the existing access synthesis configuration. See `docs/operations/local-memory-explorer.md` for viewer and access setup.

1. Import a synthetic Claude Code record through the normal importer. Include an explicit goal, confirmation of one decision, a proposed edit and an applied edit to different files, a failed check followed by a passing rerun, a command with no result, and an unanswered question. Include an injected instruction in a sanitized tool result, an anchor after the first viewer page and a second session with conflicting-looking content.
2. Run `uv run engineering-memory session-handoff claude-code:example --project orchard`, substituting the actual document ID and project from the imported fixture. Assert five sections, correct observed and unknown labels, and resolvable selected-session selectors. Repeat with `--explorer-origin http://127.0.0.1:PORT` using the running viewer's port. A mismatched project must fail without stdout.
3. Run `uv run engineering-memory explorer` and unlock the local viewer. Generate a brief from the same session and copy it. Check the clipboard Markdown and open a citation beyond the initial page. Repeat with clipboard permission denied and inspect the selectable fallback. Lock during a pending generation and confirm the old result never reappears.
4. Manually paste the brief into a fresh Codex session and ask it to identify the goal, selected decision, changed file, recorded checks, missing result and remaining question. Compare its answer to the fixture and inspect cited anchors. Record the actual result with the PR verification.
5. Run `uv run --locked pytest tests/unit/test_session_handoff.py tests/unit/test_session_handoff_cli.py tests/unit/test_deep_recall.py tests/unit/test_access_cli.py tests/contracts/test_explorer_http.py tests/integration/test_explorer_browser.py`. Run repository lint and type checks per CI. Browser tests should exercise a clipboard-capable loopback context and a synthesis fake, with assertions that no agent launch or message occurs.
